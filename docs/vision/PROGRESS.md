# Фактический статус реализации

Ветка: `codex/browser-vision-stage1`.
База: `main`, commit `80a6fdfebb976c88b1eccb2311dde7dfaa0268d0`.

## Готово к первому запуску на устройстве

- Отдельная страница наблюдения с камерой, локальным видео и явно обозначенным демо.
- Выбор камеры, фактическое разрешение, освобождение треков и остановка при зависшем видео.
- Настройка и сохранение областей, маски детектора, место героя и единицы сумм.
- TypeScript Worker: RGB, локальные блоки, 4 эталона, settle/max-wait, экономный safety poll.
- Отдельный FastAPI-сервис и версия JSON 1.0; старый мост структурно изолирован.
- OpenAI Responses API с strict JSON schema; ключ только на сервере; mock не выдаёт выдуманные карты.
- Одна глобальная операция, последний pending на сессию, лимиты, backoff, TTL и защита от старых ответов.
- Два подтверждающих захвата; null в обязательных полях не считается подтверждением.
- Диагностическая запись, экспорт после остановки и детерминированный replay состояния.
- Документация архитектуры, исходные промпты, команды проверок этапов, Docker-конфигурация.

## Проверено автоматически

- Исходный набор до изменений: **87 passed**.
- Полный Python-набор: **139 passed** (87 прежних + 52 новых).
- Vitest: **35 passed**, включая реальные detector/controller с подменёнными внешними API.
- TypeScript strict, Prettier, Ruff и проверка архитектурных границ проходят.
- Production-сборка Vite и выдача HTML/JS/CSS через реальное ASGI-приложение проходят.
- API-тесты проверяют отсутствие bridge/solver/executor в новом приложении,
  ограничение размеров, владение сессиями и отсутствие токенов в экспорте.
- Проверены гонки старых ревизий, старой эпохи, зависшей загрузки JPEG,
  независимой инвалидации, остановки и повторного подтверждения.

Синтетический замер чистого детектора, Node 24.19.0, 640×360, 10 областей,
120 измерений после прогрева: p50 **10,93 мс**, p95 **13,05 мс**, максимум **18,22 мс**.
Камерный decode, JPEG, передача в Worker и качество распознавания в этот замер не
входят. Результат сохранён в `benchmark.json`; переносить его на устройство пользователя нельзя.

## Ещё не подтверждено

- Облачный браузер отклонил тестовый адрес своей политикой доступа
  (`ERR_BLOCKED_BY_CLIENT`, затем explicit URL policy rejection). Поэтому
  визуальная приёмка и настоящий browser E2E здесь **не выполнялись**.
- Физическая вебкамера пользователя и размеченное видео стола не предоставлены.
  Порог детектора, перспектива, дрожание камеры и читаемость цифр ещё не оценены.
- Live API не вызывался: ключ и реальные кадры не использовались. Качество карт,
  сумм и мест не измерено. Успех strict JSON не доказывает правильность распознавания.
- Docker-конфигурация подготовлена, образ Docker в этой среде не собирался.
- HTTP-сервис и очередь однопроцессные, состояние/журнал хранятся в памяти.
  Записи нужно экспортировать; автоматического восстановления после рестарта нет.
- Полная история действий, side-pot decomposition, готовность к сервису решений
  и роботам остаются последующими задачами. `decision_ready=false` без исключений.

Это первая рабочая версия для пилота. Шаги 11–12 исходного плана не считаются
полностью принятыми до ручной проверки по `IMPLEMENTATION.md`. Draft PR оставлен
для проверки и первого запуска, без автоматического слияния или публикации сайта.
